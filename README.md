# Anibox

Windows 双内核代理客户端，支持 Xray 与 sing-box。当前版本 **0.5.3**。

## 使用方法

需要 Windows x64 和 WebView2。

1. 打开 `Anibox.exe`，保留同级 `cores`、`rules` 文件夹。
2. 导入节点、订阅链接或原生 JSON 配置，选择要使用的节点或配置。
3. 选择“仅开放本地端口”、系统代理或 TUN，以及分流方案。
4. 点击连接。TUN 模式需要管理员授权。

VLESS 等协议默认优先使用 Xray，Hysteria2、TUIC 默认使用 sing-box。
顶部显示上传、下载速率，悬停可查看本次累计流量。默认代理端口被占用时自动更换，主页显示实际端口。

“仅开放本地端口”需要在应用中手动填写代理地址；“系统代理”同时设置 Windows 代理，让遵循系统设置的应用自动接入。

## 配置方法

节点页编辑原生出站 JSON；内核页编辑完整 JSON，可导入、导出、校验并设为运行配置。
分享链接支持 VLESS、Trojan、Shadowsocks、Hysteria2、TUIC 及常见 Base64 订阅；其他协议可导入原生配置。

完整原生配置按原文运行，入站、DNS、分流和统计接口由配置决定。
具体规则及示例见 [配置说明](docs/CONFIGURATION.md)。

页面背景通过右上角图片按钮导入；设置中可调整透明度、恢复默认背景和修改关闭窗口行为。
背景按原始比例铺满并自动裁剪对焦，也可手动调整焦点；外观设置提供卡片效果预览。
备份包含节点凭据，请妥善保管。

## 文件位置

默认配置：`%LOCALAPPDATA%\io.anibox.desktop\workspace.json`，包含节点、订阅、原生配置和偏好设置。
背景图片副本：同级 `backgrounds` 文件夹。旧版内嵌背景会自动转为独立图片。

在“设置 → 文件目录”中可以查看实际路径、打开文件夹或更改配置与背景的存储目录。
请选择新的空目录；迁移时保留原文件。导出备份会包含背景图片。
删除背景图片后会显示默认背景，也可点击“恢复全部默认”清理所有页面背景。

日志保存在 `%LOCALAPPDATA%\io.anibox.desktop\logs`，设置中可打开该文件夹。
日志页可切换应用与内核输出，并清空对应日志；清空不会断开连接。
每类日志单文件最多 1 MB，保留当前文件和两份轮转文件，自动清理超过 7 天的文件。
日志目录不随配置存储目录迁移。原生配置指定的内核日志文件由配置自行管理。

## 更新

- **内核**：运行期间每天检查官方 GitHub 稳定版，发现新版时提示。点击更新后自动下载并校验；当前连接继续运行，新版在下次连接时使用。内核页提供手动检查和版本回退。
- **规则**：sing-box 大陆规则每 24 小时后台更新，失败继续使用缓存；Xray DAT 随官方内核包更新。原生配置自行管理引用的规则资源。
