# Anibox 0.5.2

双击 `Anibox.exe`，保持同级 `cores` 和 `rules` 文件夹完整。需 Windows x64 与 WebView2。
如果旧实例仍在运行，请先从托盘退出再打开新版。

1. 导入节点或订阅，选择节点。
2. 选择“仅开放本地端口”、系统代理或 TUN，再选择分流方案。
3. 点击连接。TUN 会请求 Windows 管理员授权；取消授权不会更改网络。

默认端口被占用时会自动避让，连接后主页显示实际使用的端口。

Xray 默认优先，Hysteria2 / TUIC 默认使用 sing-box，包括其 TUN 入口。
两种内核均可使用大陆分流。sing-box 规则每 24 小时后台更新，失败使用缓存；Xray DAT 随官方内核更新。
发现新版内核时会提示，点击更新即可自动下载、校验；重新连接后生效。内核页可手动检查更新及回退版本。

顶部显示实时上传、下载速率，悬停查看本次累计流量。原生配置未开放统计接口时显示 `—`。
节点页编辑原生出站；内核页编辑完整 JSON，保存后可设为运行配置。
原生配置不会被模板改写，其路由由 JSON 管理。原生 TUN 配置也会通过提权进程运行。

页面背景可通过右上角图片按钮导入；各页透明度和模糊在设置中调整。
背景会保持原比例自动裁剪对焦；设置中可切换手动焦点并查看预览。
默认使用浅蓝背景；设置中的“恢复默认”可移除当前页面的照片并恢复默认外观。
“设置 → 文件目录”可打开配置和背景文件夹、更改存储目录，或恢复全部默认背景。
更改存储目录时请选择新的空目录；原文件保留，备份仍包含背景图片。
节点、配置和备份均包含连接凭据，请自行保管。
